# Laura Decor

Proyecto final de Desarrollo Web (Ruta Básica).

**Laura Decor** es un emprendimiento de decoración para fiestas y eventos especiales (cumpleaños, grados, aniversarios, baby showers y celebraciones familiares).

## ¿Qué incluye la página?

- **Inicio:** Presentación de Laura Decor y nuestros servicios.
- **Catálogo:** Paquetes de decoración con filtro por tipo de evento y calculadora de precios.
- **Contacto:** Formulario para que los clientes puedan pedir su cotización o dejar sus datos.
- **Panel Admin:** Zona con clave para ver los mensajes recibidos y agregar o borrar paquetes.
- **Asistente virtual:** Chat que ayuda a elegir el paquete según el evento.
