# Laura Decor

Proyecto final de Desarrollo Web (Ruta Básica).

**Laura Decor** es un emprendimiento dedicado a la decoración de fiestas y eventos especiales (cumpleaños, baby showers, grados, aniversarios y bodas).

## Secciones de la aplicación

- **Inicio y Acerca de nosotros:** Presentación de la marca, historia y líneas de decoración.
- **Catálogo de paquetes:** Tarjetas de decoración con filtro por categoría y buscador en tiempo real.
- **Calculadora de cotización:** Calcula el valor estimado del evento aplicando descuentos, cantidad de montajes, transporte e IVA.
- **Contacto:** Formulario con validación para registrar solicitudes de clientes.
- **Panel Administrador:** Acceso con inicio de sesión para revisar solicitudes recibidas y agregar o eliminar paquetes del catálogo.
- **Asistente IA:** Chat interactivo que orienta al cliente y recomienda paquetes según su ocasión.

## Cómo ejecutar el proyecto

```bash
npm install
npm run dev
```
